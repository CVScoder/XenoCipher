Dashboard Requirements

1. Header & Status Bar

Title: “XenoCipher Secure Health Dashboard”.

Current encryption mode indicator: toggle/label showing Normal Mode or ZTM (Zero Trust Mode).

Status indicators: live connection status (online/offline), last sync timestamp.

2. Real-Time Health Data Panel

Display incoming real-time health metrics (Heart Rate, SpO₂, Step Count, Blood Pressure, etc.) in interactive cards.

Each card shows: live value, min/max over time, timestamp, and encryption status badge.

Smooth animated updates to show data streaming in.

3. Health Data Analysis Panel

Interactive line charts, area charts, and trend graphs for each health metric.

Highlight anomalies (e.g., abnormal heart rate) with color-coded alerts.

Provide insights like averages, peaks, and historical comparisons.

4. Encryption & Security Insights

Visualization of the XenoCipher encryption pipeline: LFSR → Chaotic Map → Transposition → HMAC.

Show which layers are active, with animated flow or step indicators.

Real-time alerts for events like: “Fallback to ChaCha20 initiated”, “Decryption failure detected”.

5. Extra Features

Dynamic Key Evolution Timeline → show how keys evolve per session/message.

Encryption Performance Graphs → visualize CPU/memory usage for each cipher stage.

Attack Detection Logs → table showing detected anomalies (DoS, replay attacks, failed decryptions).

Notification System → real-time popups for both health anomalies and security alerts.

6. System Metrics Panel

Show server health (CPU, memory, latency) and ESP32 device stats (battery, uptime, packet loss).

Use simple but aesthetic gauges, progress bars, or small charts.

7. User Controls & Filters

Dropdown to filter devices (ESP32-Node1, ESP32-Node2, etc.).

Date range selector for historical health data.

Toggle to switch between Raw Encrypted Data vs Decrypted Analyzed Data.
